## 一分钟上手

```
1. 菜单 VN → 剧本编辑器
2. 顶部选项目（默认 demo），点「＋ 新建章节」
3. 写第一行台词 → 点「▶ 播放」
```

就这样，能在 Game 视图里看到文字打出来。

**四个必须知道的点**：

| 你要做的事 | 去哪 |
|---|---|
| 改台词、加分支、配演出 | `VN → 剧本编辑器`（Ctrl+Shift+E） |
| 配角色（立绘 / 配音 / 字体） | `VN → 角色卡` |
| 管理多个游戏项目 | 剧本编辑器顶部的「项目」下拉 |
| 重新生成 VN 场景 | `VN → 构建场景（或重建）`（Ctrl+Shift+V） |

| 入口 | 菜单 | 快捷键 |
|---|---|---|
| 剧本编辑器 | `VN → 剧本编辑器` | **Ctrl + Shift + E** |

| 打包 Windows | `VN → 打包 Windows (x64)` | 无 |

编辑器窗口位置会被记住，下次打开还在原处。

## 项目（一个工程放多个游戏）

一个 Unity 工程里可以同时放多个**游戏项目**，每个项目有自己的章节和角色卡，互不干扰。

```
Resources/VN/Data/
├── demo/                ← 项目 A（文件夹名 = 项目名，随便起）
│   ├── characters.json     角色卡
│   ├── story01.json        第一章
│   ├── story02.json
│   └── story03.json
└── 另一个游戏/           ← 项目 B（中文、空格都可以）
    ├── characters.json
    └── chapter01.json
```

### 切换 / 新建

编辑器工具栏第一行：

```
项目 [demo ▾]   ＋ 新建项目   ＋ 新建章节
```

- **切换**：点下拉，列出 `Data/` 下所有子目录
- **新建**：点「＋ 新建项目」，输入名字（会成为文件夹名）
  - 会自动建一个空的 `characters.json`
  - 名字不能包含 `/ \ : * ? " < > |`
  - **支持中文**，例如「第二个游戏」「测试 A」

### 什么共享、什么不共享

| 内容 | 是否按项目分开 |
|---|---|
| 章节 JSON | ✅ 各项目独立 |
| 角色卡 | ✅ 各项目独立 |
| 背景 / 立绘 / 音频 / 字体 | ❌ 所有项目共享（`VN/BG`、`VN/Char`、`VN/Audio`、`VN/Fonts`） |

> 素材共享是有意的：同一套立绘/音乐想在多个项目里复用。

### VNPlayer 上对应的字段

| 字段 | 说明 |
|---|---|
| `projectId` | 项目名（= 文件夹名），如 `demo` |
| `startChapterFile` | 新游戏从哪个文件开始，如 `story01.json` |
| `characterSetFile` | 角色卡文件名，如 `characters.json` |

运行时实际路径 = `Data/<projectId>/<文件名>`。

**章节跳转**（`nextChapter` / `targetChapter`）两种写法都行：

- 只写文件名 `story02.json` → 自动拼到当前项目下（推荐，换项目不用改）
- 写完整路径 → 原样使用

### 复制一个项目

直接复制整个文件夹（连同 `.meta`），改个名就是一个新项目。

## 左侧：行列表

### 行标记（自动）

列表会自动标出涉及分支和条件的行，**不需要手动维护**：

| 标记 | 含义 |
|---|---|
| ◆ | 节点定义（这一行设了节点 ID） |
| ◇ | 有选项 |
| ？ | 有选项带条件判定 |
| → | 有跳转（节点 / 行号 / 章节） |
| # | 选项带数值效果 |

行底色也跟着变：

| 颜色 | 触发 |
|---|---|
| 红 | 有条件判定（最需要检查） |
| 橙 | 有选项 |
| 蓝 | 有跳转 |
| 绿 | 节点定义 |

### 顶部统计

```
节点 2 · 分支 1 · 条件 0 · 跳转 3 · 数值 0
```

改动任何选项或条件，统计立刻更新。写长剧本时能一眼看出哪里分叉、哪里还没接上。

### 底部按钮

| 按钮 | 作用 |
|---|---|
| ＋ 新行 | 在当前行**下面**插入一行（复制当前行的样式） |
| ⧉ 复制 | 复制当前行到下一行 |
| ✕ 删除 | 删除当前行 |
| ↑ / ↓ | 上下移动 |

## 右侧：分组详解

### 节点

| 字段 | 说明 |
|---|---|
| 节点 ID | 这一行的标识，写英文/拼音（如 `lin_arrive`）。**留空 = 不是节点** |
| 显示名 | 给分支树看的标题，如「凛出场」 |

节点是**跳转和路线图的基础**：选项跳转、`gotoNode`、存档路线记录都靠它。
右上角会显示「已被使用的节点：...」，方便查重。

### 说话人

| 操作 | 说明 |
|---|---|
| 直接输入 | 填名字，如「凛」「旁白留空」 |
| 角色卡 ▾ | 从角色卡里选，自动填名字 |
| 套用 | 把角色卡里的**立绘 + 语音 + 字体**一次填到这一行 |

下面会显示角色卡匹配结果：

```
角色卡：凛（lin）· 立绘 · 语音     [套用]
角色卡：未匹配（点「角色卡 ▾」选一个）
```

### 台词

- 支持 `[p:0.8]` 停顿标记：打字到这里停 0.8 秒
- 中文冒号、英文冒号都能识别（导入文档时用）
- 备注不进游戏，只给自己看

### 舞台 / 音频

| 字段 | 说明 |
|---|---|
| 背景 | 下拉选 `Resources/VN/BG/` 里的图 |
| 背景淡入 | 切背景的交叉淡入时长 |
| BGM | 播哪首；留空 = 保持当前 |
| BGM 音量 | 播放时的音量 / fade 指令的目标音量 |
| 淡入时长 | 只用于**播放**（0 = 用下面的淡入淡出） |
| 起始音调 | 播放时的音调（1 = 原调，0.9 = 略低沉） |
| 同一首从上次进度继续 | 停掉再播时接着上次位置 |
| BGM 指令 | 保持 / 停止 / 淡出到指定音量+变调 / 只改变音调 / 重新播放 |
| 淡入 / 淡出 | 默认时长 |
| 目标音调 | stop / fade / pitch 时的目标 |
| 变调时长 | 0 = 立即变 |
| 音效 | 单次音效，可叠加 |
| 音效音量 | |
| 高亮人物 | 说话时把这个人的名牌换成主题色（不压暗选项） |
| 转场效果 | 无 / 黑场 / 白场 / 白闪 |
| 转场时长 | |
| 舞台与文字 | **同时开始**（默认）/ **等舞台播完再说话** |
| 默认说话音 | 写在 VNPlayer 上，角色没配音时兜底 |

> `填充 BGM 音乐时，「指令」会被忽略`——想发指令就别填音乐。

### 立绘

**现在主要由角色卡驱动**：写了说话人就会自动出图，不用逐行配。

这个分组用于**手动覆盖**和**退场控制**：

| 控件 | 作用 |
|---|---|
| 本行清空所有立绘 | 三个槽位全部退场（场景切换用） |
| ＋ 添加退场 | 从角色卡选角色，让他退场（可加多个） |
| 角色退场列表 | 每条显示「凛（lin）」+ 删除按钮 |
| 立绘条目 | 手动配：槽位 / 图片 / 角色 / 表情 / 偏移 / 缩放 / 动作 |

**优先级**：行级立绘条目 > 角色卡自动立绘。

**退场的区别**：

| 方式 | 影响范围 | 之后会不会被角色卡加回来 |
|---|---|---|
| 本行清空所有立绘 | 全部 | 会（下一行有角色说话就出图） |
| 角色退场（exitCharacters） | 指定角色 | **不会** |
| 立绘条目勾「隐藏」 | 指定槽位 | 会 |

### 文字演出

| 字段 | 说明 |
|---|---|
| 字号 | 8~96，有 24/36/48/60 快捷值（像素字体建议用 12 的倍数） |
| 字体 | 按行覆盖；留空用角色卡字体，再留空用默认 |
| 速度 | 慢 / 中 / 快 / 瞬间，或直接填 charsPerSecond |
| 特效 | 无 / 抖动 / 波浪 / 呼吸 / 故障 |
| 强度 / 速度 | 特效参数，字号越大位移越大 |
| 颜色 | 十六进制 |
| 描边 | 开关 |

### 镜头

嵌套在「舞台 / 音频」里，**只作用于背景和立绘**，对话框和菜单不受影响。

| 字段 | 说明 |
|---|---|
| 启用镜头 | 开关 |
| 偏移 X/Y | 平移 |
| 缩放 | 推拉 |
| 时长 | 补间时长 |
| 晃动模式 | 无 / 轻 / 中 / 重 |
| 晃动时长 / 强度 | |

### 失明 / 模糊滤镜

| 字段 | 说明 |
|---|---|
| 启用 | 开关 |
| 失明强度 | 0 = 正常，1 = 完全失明（黑白 + 提亮 + 模糊 + 扭曲 + 暗角） |
| 渐变时长 | 从当前强度过渡到目标值的秒数 |

**只影响背景层**，对话框、名牌、菜单都不受影响。
强度是**累积**的：上一行 0.35、这一行 0.7，就从 0.35 平滑过渡到 0.7。

### 演出顺序表

时间轴：每行是一个时间点，同一行勾多个动作 = 同时发生。

```
时间(秒)  备注        背景 立绘 镜头 转场 文字 音效 BGM 音轨
  0.0    黑场+音乐     □   □   □   ☑   □   □   ☑   □
  0.35   换景推镜       ☑   ☑   ☑   □   □   ☑   □   ☑
  1.2    开始说话       □   □   □   □   ☑   □   □   □
```

| 规则 | 说明 |
|---|---|
| 执行顺序 | 按时间从小到大 |
| 同时 | 同一行的勾选一起生效 |
| 没有「文字」步骤 | 序列结束时自动开始打字（不会卡住） |
| 播放中点击 | 跳过剩余演出，立刻补齐舞台和文字 |
| 留空 | 回到默认流程（全部立刻执行） |

**用例**：「镜头晃动 + 立绘入场在 0.3 秒，文字 1 秒后才开始」→ 两行搞定。

### 多音轨

每条 = 一条音轨指令。**音轨名不同就能同时出声**。

```
音轨: [bgm ▾]      指令: [play ▾]
音频: [雨夜.ogg ▾]
时间 [0.0]  音量 [0.6]  淡入淡出 [1.0]
循环 ☑
```

| 规则 | 说明 |
|---|---|
| 同名音轨 | 互相替换（交叉淡入淡出） |
| 不同名 | 同时播放，各自独立 |
| 时间 | 相对本行开始的秒数 |
| 指令 | play / stop / pitch |

常用音轨：`bgm`（主音乐）、`ambient`（环境底噪）、`rain`、`heartbeat`。

### 结局 / CG / 视频

| 字段 | 说明 |
|---|---|
| 本行不显示立绘 | 结局 / CG 段用，连角色卡自动出图也关掉 |
| 结局 CG | 独立全屏层（**会盖住对话框**，适合没台词的纯图结局） |
| 结局视频 | 填了就优先播视频（需要导入成 VideoClip） |
| 循环播放 | |
| 到达本行后结束游戏 | 结束前等待 + 返回主菜单 |

**想在 CG 上显示台词** → 把 CG 填到「背景」字段，不要用「结局 CG」。

### 分支 / 选项 / 数值

| 字段 | 说明 |
|---|---|
| 跳转到节点 / 行号 | 播完这行自动跳转（一般不用） |
| 下一章 | 播完这行切到别的章节 JSON |
| 选项 | 每个选项：文字 / 目标节点 / 条件 / 数值效果 / 锁定样式 |
| 条件 | 如 `affection >= 2 && visited(route_a)`，不满足时默认隐藏 |
| 显示为灰色 | 条件不满足时显示但不可点，配合「锁定文字」 |

**条件表达式**支持：比较、`visited(节点)`、`&&`、`||`、`!`、括号。

## 角色卡编辑器

菜单 `VN → 角色卡`。

```
┌ 角色（5）───────┐ ┌ 凛（lin）──────────────┐
│ 凛（lin）       │ │ id: [lin]              │
│ 薇（wei）       │ │ 显示名: [凛]            │
│ 我（me）        │ │ 在剧本里自动出图 ☑      │
│ ？？？（unknown）│ │ 默认立绘: [she/normal ▾]│
│ 外来者1         │ │   ┌──────────────┐     │
└─────────────────┘ │   │  （预览）      │     │
                    │   └──────────────┘     │
                    │ 立绘位置: [center ▾]    │
                    │ 语音文件: [voice_she ▾] │
                    │ 模式: [char ▾]          │
                    │ 音量 / 抖动 / 每隔几字  │
                    │ 字体: [（默认）▾]        │
                    │ 备注: [_______________] │
                    └────────────────────────┘
```

### 核心概念

**配一次角色，剧本里只要写名字**：

| 配置项 | 效果 |
|---|---|
| 在剧本里自动出图 | 关掉 = 只说话不出图（第一人称 / 未露面的角色） |
| 默认立绘 | 角色卡驱动的图 |
| 立绘位置 | left / center / right |
| 语音文件 + 模式 | `char` 每字触发 / `loop` 循环 / `none` 静音 |
| 字体 | 让不同角色用不同字体 |

### 保存时自动同步剧本

点「保存」后会自动扫描 `Data/` 下所有剧本：

| 情况 | 动作 |
|---|---|
| 角色卡**有**立绘 | 把剧本里的 `sprite` 更新成角色卡路径 |
| 角色卡**没有**立绘 | 从剧本里**删掉**这条立绘 |
| `character` 为空 | 不动（你手配的立绘不受影响） |

底部会显示结果，例如：

```
已同步 2 个剧本：更新 0 处立绘，移除 2 处（角色卡已无立绘）
```

### 缺失提醒

如果有剧本引用了角色卡里**已经不存在的角色**，窗口底部会显示黄色警告：

```
⚠ 有 1 处剧本引用了角色卡里已经不存在的角色：
   ghost（story02.json）
```

打开窗口时就会检查，不用先保存。

## 场景构建

菜单 `VN → 构建场景（或重建）`（Ctrl+Shift+V）。

**什么时候需要重建**：

| 情况 | 要重建吗 |
|---|---|
| 改剧本内容 | 不用 |
| 改角色卡 | 不用 |
| 加资源（图 / 音频 / 字体） | 不用 |
| 代码里加了新的 UI 字段（如音轨、Voice 通道） | **要** |
| 场景层级被改坏了 | 要 |

重建会覆盖 `Assets/VN/Scenes/VN.unity`，生成：

```
VN Root
├─ VNPlayer
├─ VNAudioManager (BGM_A / BGM_B / SFX / Voice)
VN Canvas
└─ VN Frame
   └─ Stage
      ├─ Background (BG_A / BG_B)
      └─ Actors (Actor_Left / Actor_Center / Actor_Right)
```

> 重建后如果场景里 VNPlayer 的字段（起始章节、标题等）被重置，记得重新检查一遍。

## 预览 vs 播放

| | 👁 预览 | ▶ 播放 |
|---|---|---|
| 是否进 Play 模式 | 否（编辑器里直接渲染） | 是 |
| 从哪开始 | 选中的行 | 选中的行 |
| 章节卡片 | 不播 | 播 |
| 用途 | 快速看立绘位置、镜头、字号 | 完整测试流程、分支、存档 |
| 会不会改场景 | **不会**（临时借用路径后还原） | 不会（测试行用 SessionState 传参） |

**重要**：编辑器里的「▶ 播放」不会污染场景文件——退出 Play 后，直接点 Unity 的 Play 按钮仍然会从主菜单正常开始。

## 打包

菜单 `VN → 打包 Windows (x64)`。

- 自动把 `VN.unity` 加进 Build Settings
- 输出到 `Build/nago2026_recall.exe`
- 完成后自动在资源管理器里打开目录
- 大约 50~60 秒

**打包前检查**：

1. `Assets/VN/Data_Legacy/` 里的测试剧本**不会**被打包（不在 Resources）
2. 确认 `resources.assets` 里没有意外的测试资源
3. 想换分辨率：`Project Settings → Player → Resolution and Presentation`

**注意**：打包时 Unity 主线程被占满，MCP 会短暂失联，这是正常的。

## 常用工作流

### 新增一个角色

```
1. VN → 角色卡 → ＋ 新建角色
2. 填 id（英文）和显示名（剧本里的名字）
3. 选立绘、选语音、选位置
4. 保存
5. 剧本里写说话人 → 自动出图
```

### 让角色某一刻退场

```
1. 在那一行点「＋ 添加退场」→ 选角色
2. 之后这个角色即使再说话也不会被自动加回来
```

### 加一个分支

```
1. 在想分叉的行点「＋ 添加选项」
2. 每个选项填文字 + 目标节点
3. 在目标行设置「节点 ID」
4. 需要条件时填 condition（如 affection >= 2）
5. 左侧列表会显示 ◇ 和橙色底
```

### 加一个结局

```
1. 复制最后那条结局行
2. 改 endingCg / endingVideo / 背景
3. 改台词
4. endGame 保持勾选
```

### 换角色的立绘

```
1. VN → 角色卡 → 选角色 → 换图
2. 保存（自动同步到所有剧本）
```

### 调某一行的演出时序

```
1. 打开「演出顺序表」
2. ＋ 添加步骤，填时间
3. 勾选要同时发生的动作
```

## 素材规范

| 类型 | 位置 | 规范 |
|---|---|---|
| 背景 | `Resources/VN/BG/` | PNG/JPG，任意比例（运行时等比裁切，不变形） |
| 立绘 | `Resources/VN/Char/<角色id>/<表情>.png` | **透明 PNG**，画布高度一致，换表情时脚不会跳 |
| BGM | `Resources/VN/Audio/BGM/` | OGG / WAV，自动循环 |
| 音效 | `Resources/VN/Audio/SFX/` | 短音频 |
| 说话音 | `Resources/VN/Audio/Voice/` | 建议 0.05~0.3 秒 |
| 字体 | `Assets/VN/Fonts/` | TTF，像素字体建议字号用 12 的倍数 |
| 剧本 | `Resources/VN/Data/*.json` | 编辑器自动生成，不用手改 |
| 角色卡 | `Resources/VN/Data/characters.json` | 用角色卡编辑器改 |

**导入设置会自动处理**：`Assets/VN/` 下的图会被设成 Sprite + Point 过滤 + 无压缩（像素风不糊）。

## 故障排查

| 现象 | 原因 | 解决 |
|---|---|---|
| 立绘出现两个 | 剧本配的槽位和角色卡不一致 | 角色卡保存会自动对齐；或手动改成同一个槽位 |
| 旁白自动借用了别人的声音 | 名字匹配到了在场角色 | 检查说话人名字；或给该角色配 `voiceMode: none` |
| 打开就模糊 | 失明滤镜强度没归零 | 检查行里的 `useBlind` / `blind`；默认 0 应该是清晰的 |
| 新游戏跳到了后面的章节 | `startChapter` 被改 | 检查 `VNPlayer.startChapter` 是否指向 story01 |
| 编辑器播放后，直接 Play 从中间开始 | 旧版本的 bug | 已修复：现在用 SessionState 传参，不写场景 |
| 保存角色卡后剧本没变 | 没点「保存」 | 工具栏会显示 `● 未保存` |
| 改完代码后 VN 场景缺 UI | 新字段需要重建场景 | `VN → 构建场景（或重建）` |
| 打包报错找不到脚本 | 编译错误 | 先看 Console，清掉红色错误 |
