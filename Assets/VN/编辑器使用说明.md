## 一分钟上手

```
1. 菜单 VN → 剧本编辑器
2. 顶部选项目（默认 demo），点「＋ 新建章节」
3. 写第一行台词 → 点「▶ 播放」
```

就这样，能在 Game 视图里看到文字打出来。

**四个必须知道的点**：

| 你要做的事 | 去哪 |
|---|---|
| 改台词、加分支、配演出 | `VN → 剧本编辑器`（Ctrl+Shift+E） |
| 配角色（立绘 / 配音 / 字体） | `VN → 角色卡` |
| 管理多个游戏项目 | 剧本编辑器顶部的「项目」下拉 |
| 重新生成 VN 场景 | `VN → 构建场景（或重建）`（Ctrl+Shift+V） |

## 打开方式

| 入口 | 菜单 | 快捷键 |
|---|---|---|
| 调试启动器 | `VN → 调试启动器` | 无 |
| 剧本编辑器 | `VN → 剧本编辑器` | **Ctrl + Shift + E** |
| 角色卡 | `VN → 角色卡` | 无 |
| 构建场景 | `VN → 构建场景（或重建）` | **Ctrl + Shift + V** |
| 打包 Windows | `VN → 打包 Windows (x64)` | 无 |

编辑器窗口位置会被记住，下次打开还在原处。

## 调试启动器

想试别的项目的剧情时，不用改场景里的 VNPlayer——用调试启动器选好再启动：

```
VN → 调试启动器

┌ 选择要调试的游戏项目与章节 ─────────┐
│ 项目   [demo ▾]              ↻      │
│ 章节   [story01.json ▾]            │
│ 从第几行开始（0 起）  0             │
│                                     │
│ ☑ 跳过主菜单，直接进剧情             │
│ ☐ 允许跨项目跳转（meta / 彩蛋）      │
│                                     │
│           [▶ 开始调试]              │
├─────────────────────────────────────┤
│ 场景里的 VNPlayer                    │
│ 当前项目   demo                      │
│ 起始章节   story01.json              │
│ 跨项目     隔离                      │
│ 实际路径   Assets/.../demo/story01   │
└─────────────────────────────────────┘
```

| 选项 | 说明 |
|---|---|
| 项目 | `Data/` 下的所有项目 |
| 章节 | 只列**当前项目**的 JSON，不会串到别的游戏 |
| 从第几行开始 | 直接跳到某一行的内容（0 = 第一行） |
| 跳过主菜单 | 勾上直接进剧情；不勾会先显示主菜单（测标题画面用） |
| 允许跨项目跳转 | 默认关 = 各游戏完全隔离；见下面 |

点「开始调试」会：

1. 把项目 / 章节 / 跨项目开关写进 **VNPlayer（内存，不保存场景）**
2. 自动进入 Play 模式
3. 退出 Play 后场景文件保持原样

选择会被记住，下次打开窗口还是上次的。

### 跨项目跳转（meta / 彩蛋）

默认 **关闭**，各游戏的章节互不串通。

勾上「允许跨项目跳转」后会展开目标配置：

```
☑ 允许跨项目跳转（meta / 彩蛋）
    跳转目标（调试时直接从这里开始）
    目标项目  [gameB ▾]
    目标章节  [story02.json ▾]
    跳转到    [第一行（默认） ▾]   ← 第一行 / 指定行 / 随机行
    启动后直接进入目标项目的第一行
```

| 选项 | 说明 |
|---|---|
| 目标项目 | 除当前项目外的其他项目 |
| 目标章节 | 只列目标项目的 JSON |
| 第一行（默认） | 启动后直接进目标项目第一行 |
| 指定行 | 填行号，直接进那一行 |
| 随机行 | 每次启动随机一行（会显示范围，如 `0 ~ 64（共 65 行）`） |

**点「开始调试」会直接从目标项目启动**，`VNPlayer` 的 `projectId` 也切过去，
角色卡跟着换成目标项目的——等于跳过前面的剧情，直接测那一段。

#### 正式版里的彩蛋写法

调试器只是预览。想让游戏里真的跳：

1. 在 `VNPlayer` 上勾 `allowCrossProject`
2. 在剧本行填：

```json
{
  "text": "……你听见了另一个世界的声音。",
  "crossProjectChapter": "gameB/story02.json",
  "crossProjectLine": 0
}
```

或者随机跳：

```json
{
  "text": "……",
  "crossProjectRandom": true
}
```

随机跳会从 `VNPlayer.crossProjectPool`（字符串数组，填项目名）里随机挑一个项目，
再从那个项目里随机挑一章。

**跳过去会自动切项目**，角色卡也跟着换成目标项目的，不会出现「用着 A 的角色卡读 B 的剧本」。

`allowCrossProject` 关掉时，上面这些字段全部被忽略——**不会意外串到别的游戏**。

## 项目（一个工程放多个游戏）

一个 Unity 工程里可以同时放多个**游戏项目**。**一个项目 = `Resources` 下的一个文件夹**，里面自带一整套资源。

```
Assets/VN/Resources/
├── Shaders/                  框架自带的 shader（所有项目共用）
├── Recall/                   ← 项目 A：项目名就是文件夹名
│   ├── Arts/                 美术资产
│   │   ├── BG/                  背景
│   │   ├── CG/                  结局图 / 全屏插画
│   │   └── Char/                立绘（按角色 id 分子目录）
│   ├── Audio/                音频
│   │   ├── BGM/
│   │   ├── SFX/
│   │   └── Voice/
│   └── Data/                 数据
│       ├── characters.json      角色卡
│       ├── story01.json         第一章
│       ├── story02.json
│       └── story03.json
└── 另一个游戏/               ← 项目 B：结构完全一样
    ├── Arts/{BG,CG,Char}/
    ├── Audio/{BGM,SFX,Voice}/
    └── Data/characters.json
```

### 切换 / 新建

```
项目 [Recall ▾]  ＋新建项目  ✎重命名项目
```

- **切换**：下拉列出 `Resources/` 下的一级文件夹
- **新建**：点「＋ 新建项目」，输入名字 → **自动按模板建好** `Arts/BG`、`Arts/CG`、`Arts/Char`、`Audio/BGM`、`Audio/SFX`、`Audio/Voice`、`Data/characters.json`
  - 名字不能包含 `/ \ : * ? " < > |`
  - **支持中文**，例如「第二个游戏」「测试 A」

### 什么共享、什么不共享

| 内容 | 是否按项目分开 |
|---|---|
| 章节 JSON | ✅ 各项目独立（`<项目>/Data`） |
| 角色卡 | ✅ 各项目独立（`<项目>/Data/characters.json`） |
| 背景 / CG / 立绘 / 音频 | ✅ **也按项目独立**（`<项目>/Arts`、`<项目>/Audio`） |
| Shader | ❌ 所有项目共用（`Resources/Shaders`） |
| 字体 | ❌ 所有项目共用（`Assets/VN/Fonts`） |

> 想复用一个项目的素材时，直接把文件复制到目标项目的对应目录。

### VNPlayer 上对应的字段

| 字段 | 说明 |
|---|---|
| `projectId` | 项目名（= `Resources` 下的文件夹名），如 `Recall` |
| `startChapterFile` | 新游戏从哪个文件开始，如 `story01.json` |
| `characterSetFile` | 角色卡文件名，如 `characters.json` |

运行时路径自动推导：

```
资源根     Assets/VN/Resources/<projectId>
章节       <资源根>/Data/<startChapterFile>
角色卡     <资源根>/Data/<characterSetFile>
背景       <资源根>/Arts/BG
CG         <资源根>/Arts/CG
立绘       <资源根>/Arts/Char/<角色id>/
音频       <资源根>/Audio/{BGM,SFX,Voice}
```

**章节跳转**（`nextChapter` / `targetChapter`）两种写法都行：

- 只写文件名 `story02.json` → 自动拼到当前项目下（推荐，换项目不用改）
- 写完整路径 → 原样使用

### 复制一个项目

直接复制整个文件夹（连同 `.meta`），改个名就是一个新项目。

### 重命名项目 / 章节

| 操作 | 位置 |
|---|---|
| 重命名项目 | 项目栏的「✎ 重命名项目」 |
| 重命名章节 | 第二行工具栏的「✎ 重命名章节」 |

- 输入新名字（支持中文），确定即可
- 项目重命名 = 文件夹改名，里面的章节和角色卡跟着走
- 章节重命名后，当前打开的路径会自动更新
- 已经有同名项目/章节时会拒绝，不会覆盖

> 如果剧本里用**完整路径**引用了被改名的章节，需要手动改一下；
> 用文件名（`story02.json`）写的跳转不受影响。

### 跨项目用角色卡

在剧本里点「角色卡 ▾」时，菜单分两部分：

```
角色卡 ▾
├─ 凛（lin）                  ← 本项目角色，直接列出来
├─ 薇（wei）
├─ ─────────────
└─ 来自其他项目的角色卡 ▸
     ├─ demo ▸
     │   ├─ 凛（lin）
     │   └─ 我（me）
     └─ 另一个游戏 ▸
         └─ ...
```

- **本项目角色**：平铺，点一下直接用
- **其他项目角色**：收在「来自其他项目的角色卡 / 项目名 / 角色名」三层子菜单里
- 已经在当前项目的角色会显示 `[已在本项目]` 并置灰，不会重复

**点选其他项目的角色时会自动复制一份到当前项目**：

- 复制的是完整角色卡（立绘 / 语音 / 字体 / 备注全带上）
- 复制后当前项目单独打包也不会缺数据
- **同一个 id 只会复制一次**，之后再选就是直接用它，不会重复占用

> 复制的是角色卡配置，立绘/音频文件本身是全项目共享的，不会重复占磁盘。

## 左侧：行列表

### 行标记（自动）

列表会自动标出涉及分支和条件的行，**不需要手动维护**：

| 标记 | 含义 |
|---|---|
| ◆ | 节点定义（这一行设了节点 ID） |
| ◇ | 有选项 |
| ？ | 有选项带条件判定 |
| → | 有跳转（节点 / 行号 / 章节） |
| # | 选项带数值效果 |

行底色也跟着变：

| 颜色 | 触发 |
|---|---|
| 红 | 有条件判定（最需要检查） |
| 橙 | 有选项 |
| 蓝 | 有跳转 |
| 绿 | 节点定义 |

### 顶部统计

```
节点 2 · 分支 1 · 条件 0 · 跳转 3 · 数值 0
```

改动任何选项或条件，统计立刻更新。写长剧本时能一眼看出哪里分叉、哪里还没接上。

### 底部按钮

| 按钮 | 作用 |
|---|---|
| ＋ 新行 | 在当前行**下面**插入一行（复制当前行的样式） |
| ⧉ 复制 | 复制当前行到下一行 |
| ✕ 删除 | 删除当前行 |
| ↑ / ↓ | 上下移动 |

## 右侧：分组详解

### 节点

| 字段 | 说明 |
|---|---|
| 节点 ID | 这一行的标识，写英文/拼音（如 `lin_arrive`）。**留空 = 不是节点** |
| 显示名 | 给分支树看的标题，如「凛出场」 |

节点是**跳转和路线图的基础**：选项跳转、`gotoNode`、存档路线记录都靠它。
右上角会显示「已被使用的节点：...」，方便查重。

### 说话人

| 操作 | 说明 |
|---|---|
| 直接输入 | 填名字，如「凛」「旁白留空」 |
| 角色卡 ▾ | 从角色卡里选，自动填名字 |
| 套用 | 把角色卡里的**立绘 + 语音 + 字体**一次填到这一行 |

下面会显示角色卡匹配结果：

```
角色卡：凛（lin）· 立绘 · 语音     [套用]
角色卡：未匹配（点「角色卡 ▾」选一个）
```

### 台词

- 支持 `[p:0.8]` 停顿标记：打字到这里停 0.8 秒
- 中文冒号、英文冒号都能识别（导入文档时用）
- 备注不进游戏，只给自己看

### 舞台 / 音频

| 字段 | 说明 |
|---|---|
| 背景 | 下拉选 `Resources/VN/BG/` 里的图 |
| 背景淡入 | 切背景的交叉淡入时长 |
| BGM | 播哪首；留空 = 保持当前 |
| BGM 音量 | 播放时的音量 / fade 指令的目标音量 |
| 淡入时长 | 只用于**播放**（0 = 用下面的淡入淡出） |
| 起始音调 | 播放时的音调（1 = 原调，0.9 = 略低沉） |
| 同一首从上次进度继续 | 停掉再播时接着上次位置 |
| BGM 指令 | 保持 / 停止 / 淡出到指定音量+变调 / 只改变音调 / 重新播放 |
| 淡入 / 淡出 | 默认时长 |
| 目标音调 | stop / fade / pitch 时的目标 |
| 变调时长 | 0 = 立即变 |
| 音效 | 单次音效，可叠加 |
| 音效音量 | |
| 高亮人物 | 说话时把这个人的名牌换成主题色（不压暗选项） |
| 转场效果 | 无 / 黑场 / 白场 / 白闪 |
| 转场时长 | |
| 舞台与文字 | **同时开始**（默认）/ **等舞台播完再说话** |
| 默认说话音 | 写在 VNPlayer 上，角色没配音时兜底 |

> `填充 BGM 音乐时，「指令」会被忽略`——想发指令就别填音乐。

### 立绘

**现在主要由角色卡驱动**：写了说话人就会自动出图，不用逐行配。

这个分组用于**手动覆盖**和**退场控制**：

| 控件 | 作用 |
|---|---|
| 本行清空所有立绘 | 三个槽位全部退场（场景切换用） |
| ＋ 添加退场 | 从角色卡选角色，让他退场（可加多个） |
| 角色退场列表 | 每条显示「凛（lin）」+ 删除按钮 |
| 立绘条目 | 手动配：槽位 / 图片 / 角色 / 表情 / 偏移 / 缩放 / 动作 |

**优先级**：行级立绘条目 > 角色卡自动立绘。

**退场的区别**：

| 方式 | 影响范围 | 之后会不会被角色卡加回来 |
|---|---|---|
| 本行清空所有立绘 | 全部 | 会（下一行有角色说话就出图） |
| 角色退场（exitCharacters） | 指定角色 | **不会** |
| 立绘条目勾「隐藏」 | 指定槽位 | 会 |

### 文字演出

| 字段 | 说明 |
|---|---|
| 字号 | 8~96，有 24/36/48/60 快捷值（像素字体建议用 12 的倍数） |
| 字体 | 按行覆盖；留空用角色卡字体，再留空用默认 |
| 速度 | 慢 / 中 / 快 / 瞬间，或直接填 charsPerSecond |
| 特效 | 无 / 抖动 / 波浪 / 呼吸 / 故障 |
| 强度 / 速度 | 特效参数，字号越大位移越大 |
| 颜色 | 十六进制 |
| 描边 | 开关 |

### 镜头

嵌套在「舞台 / 音频」里，**只作用于背景和立绘**，对话框和菜单不受影响。

| 字段 | 说明 |
|---|---|
| 启用镜头 | 开关 |
| 偏移 X/Y | 平移 |
| 缩放 | 推拉 |
| 时长 | 补间时长 |
| 晃动模式 | 无 / 轻 / 中 / 重 |
| 晃动时长 / 强度 | |

### 失明 / 模糊滤镜

| 字段 | 说明 |
|---|---|
| 启用 | 开关 |
| 失明强度 | 0 = 正常，1 = 完全失明（黑白 + 提亮 + 模糊 + 扭曲 + 暗角） |
| 渐变时长 | 从当前强度过渡到目标值的秒数 |

**只影响背景层**，对话框、名牌、菜单都不受影响。
强度是**累积**的：上一行 0.35、这一行 0.7，就从 0.35 平滑过渡到 0.7。

### 自定义效果（插件）

框架自带的效果（文字特效 / 镜头 / 立绘动作 / 转场 / 滤镜）都是写死的代码。
想加自己的演出（新动画、粒子、特殊镜头、UI 演出），**不用改框架**——写一个实现 `IVNStageEffect` 的脚本即可。

```
▼ 自定义效果（插件）
  效果  [（无） ▾]  ↻
  参数  [dist=8;time=0.5]
```

#### 写一个效果

```csharp
public class MyShake : IVNStageEffect
{
    public string Id => "my_shake";           // 剧本里填这个
    public string DisplayName => "我的摇晃";   // 编辑器下拉显示这个

    public IEnumerator Play(VNEffectContext ctx)
    {
        var rect = ctx.dialogueRoot;
        var origin = rect.anchoredPosition;

        float t = 0f;
        while (t < 0.5f)
        {
            t += Time.deltaTime;
            rect.anchoredPosition = origin + new Vector2(Mathf.Sin(t * 60f) * 8f, 0f);
            yield return null;
        }

        rect.anchoredPosition = origin;
    }
}
```

存到 `Assets` 下任意位置，编辑器会自动扫描到（下拉里出现）。
剧本行选中它 → 播放到这一行时执行。

#### ctx（VNEffectContext）里有什么

| 成员 | 说明 |
|---|---|
| `player` | 播放器本体，可以访问公开字段 / 方法 |
| `line` / `lineIndex` | 当前行 / 行号 |
| `parameters` | 剧本里填的参数（自由字符串） |
| `stageRoot` | 镜头容器（背景 + 立绘都在里面） |
| `backgroundA` / `backgroundB` | 两层背景（交叉淡入用） |
| `actorLeft` / `actorCenter` / `actorRight` | 三个立绘槽位的 `Image` |
| `dialogueRoot` | 对话框根节点（整体位移 / 缩放 / 淡出） |
| `GetActor("center")` | 按槽位取立绘 |
| `GetParam("key", "默认")` | 读参数 |
| `GetParamFloat("key", 1f)` | 读 float 参数 |

#### 参数

剧本里写成 `key=value;key2=value2`，效果里用 `ctx.GetParamFloat("key", 默认值)` 读。

#### 行为

- 效果和默认演出**同时开始**，不阻塞玩家推进
- 想阻塞的话，在效果里自己控制时长 / 关掉输入
- 效果执行出错会打红字日志，不影响剧情推进

#### 示例

`Assets/VN/Examples/VNExampleEffects.cs` 里有 4 个可直接用的例子：

| Id | 效果 | 参数 |
|---|---|---|
| `dialogue_shake` | 对话框晃动 | `dist=8;time=0.45` |
| `actor_bounce` | 立绘弹跳 | `slot=center;height=40;time=0.35` |
| `camera_kick` | 镜头推近回弹 | `zoom=1.12;time=0.7` |
| `screen_flash` | 全屏闪色 | `color=#FF3060;time=0.35` |

> 下拉里没有新写的效果时，点旁边的 `↻` 重新扫描。

#### 代码放在哪

| 文件 | 位置 |
|---|---|
| 插件接口 `IVNStageEffect` / 上下文 / 注册表 | `Assets/VN/Scripts/Effects/VNStageEffect.cs` |
| 文字特效 `VNTextEffect`（抖动/波浪/呼吸/故障） | `Assets/VN/Scripts/Effects/VNTextEffect.cs` |
| 你自己写的效果 | 任意位置都行，建议 `Assets/VN/Effects/` 或 `Assets/VN/Scripts/Effects/` |
| 示例 | `Assets/VN/Examples/VNExampleEffects.cs` |

### 演出顺序表

时间轴：每行是一个时间点，同一行勾多个动作 = 同时发生。

```
时间(秒)  备注        背景 立绘 镜头 转场 文字 音效 BGM 音轨
  0.0    黑场+音乐     □   □   □   ☑   □   □   ☑   □
  0.35   换景推镜       ☑   ☑   ☑   □   □   ☑   □   ☑
  1.2    开始说话       □   □   □   □   ☑   □   □   □
```

| 规则 | 说明 |
|---|---|
| 执行顺序 | 按时间从小到大 |
| 同时 | 同一行的勾选一起生效 |
| 没有「文字」步骤 | 序列结束时自动开始打字（不会卡住） |
| 播放中点击 | 跳过剩余演出，立刻补齐舞台和文字 |
| 留空 | 回到默认流程（全部立刻执行） |

**用例**：「镜头晃动 + 立绘入场在 0.3 秒，文字 1 秒后才开始」→ 两行搞定。

### 多音轨

每条 = 一条音轨指令。**音轨名不同就能同时出声**。

```
音轨: [bgm ▾]      指令: [play ▾]
音频: [雨夜.ogg ▾]
时间 [0.0]  音量 [0.6]  淡入淡出 [1.0]
循环 ☑
```

| 规则 | 说明 |
|---|---|
| 同名音轨 | 互相替换（交叉淡入淡出） |
| 不同名 | 同时播放，各自独立 |
| 时间 | 相对本行开始的秒数 |
| 指令 | play / stop / pitch |

常用音轨：`bgm`（主音乐）、`ambient`（环境底噪）、`rain`、`heartbeat`。

### 结局 / CG / 视频

| 字段 | 说明 |
|---|---|
| 本行不显示立绘 | 结局 / CG 段用，连角色卡自动出图也关掉 |
| 结局 CG | 独立全屏层（**会盖住对话框**，适合没台词的纯图结局） |
| 结局视频 | 填了就优先播视频（需要导入成 VideoClip） |
| 循环播放 | |
| 到达本行后结束游戏 | 结束前等待 + 返回主菜单 |

**想在 CG 上显示台词** → 把 CG 填到「背景」字段，不要用「结局 CG」。

### 分支 / 选项 / 数值

| 字段 | 说明 |
|---|---|
| 跳转到节点 / 行号 | 播完这行自动跳转（一般不用） |
| 下一章 | 播完这行切到别的章节 JSON |
| 选项 | 每个选项：文字 / 目标节点 / 条件 / 数值效果 / 锁定样式 |
| 条件 | 如 `affection >= 2 && visited(route_a)`，不满足时默认隐藏 |
| 显示为灰色 | 条件不满足时显示但不可点，配合「锁定文字」 |

**条件表达式**支持：比较、`visited(节点)`、`&&`、`||`、`!`、括号。

## 角色卡编辑器

菜单 `VN → 角色卡`。

```
┌ 角色（5）───────┐ ┌ 凛（lin）──────────────┐
│ 凛（lin）       │ │ id: [lin]              │
│ 薇（wei）       │ │ 显示名: [凛]            │
│ 我（me）        │ │ 在剧本里自动出图 ☑      │
│ ？？？（unknown）│ │ 默认立绘: [she/normal ▾]│
│ 外来者1         │ │   ┌──────────────┐     │
└─────────────────┘ │   │  （预览）      │     │
                    │   └──────────────┘     │
                    │ 立绘位置: [center ▾]    │
                    │ 语音文件: [voice_she ▾] │
                    │ 模式: [char ▾]          │
                    │ 音量 / 抖动 / 每隔几字  │
                    │ 字体: [（默认）▾]        │
                    │ 备注: [_______________] │
                    └────────────────────────┘
```

### 核心概念

**配一次角色，剧本里只要写名字**：

| 配置项 | 效果 |
|---|---|
| 在剧本里自动出图 | 关掉 = 只说话不出图（第一人称 / 未露面的角色） |
| 默认立绘 | 角色卡驱动的图 |
| 立绘位置 | left / center / right |
| 语音文件 + 模式 | `char` 每字触发 / `loop` 循环 / `none` 静音 |
| 字体 | 让不同角色用不同字体 |

### 保存时自动同步剧本

点「保存」后会自动扫描 `Data/` 下所有剧本：

| 情况 | 动作 |
|---|---|
| 角色卡**有**立绘 | 把剧本里的 `sprite` 更新成角色卡路径 |
| 角色卡**没有**立绘 | 从剧本里**删掉**这条立绘 |
| `character` 为空 | 不动（你手配的立绘不受影响） |

底部会显示结果，例如：

```
已同步 2 个剧本：更新 0 处立绘，移除 2 处（角色卡已无立绘）
```

### 缺失提醒

如果有剧本引用了角色卡里**已经不存在的角色**，窗口底部会显示黄色警告：

```
⚠ 有 1 处剧本引用了角色卡里已经不存在的角色：
   ghost（story02.json）
```

打开窗口时就会检查，不用先保存。

## 场景构建

菜单 `VN → 构建场景（或重建）`（Ctrl+Shift+V）。

**什么时候需要重建**：

| 情况 | 要重建吗 |
|---|---|
| 改剧本内容 | 不用 |
| 改角色卡 | 不用 |
| 加资源（图 / 音频 / 字体） | 不用 |
| 代码里加了新的 UI 字段（如音轨、Voice 通道） | **要** |
| 场景层级被改坏了 | 要 |

重建会覆盖 `Assets/VN/Scenes/VN.unity`，生成：

```
VN Root
├─ VNPlayer
├─ VNAudioManager (BGM_A / BGM_B / SFX / Voice)
VN Canvas
└─ VN Frame
   └─ Stage
      ├─ Background (BG_A / BG_B)
      └─ Actors (Actor_Left / Actor_Center / Actor_Right)
```

> 重建后如果场景里 VNPlayer 的字段（起始章节、标题等）被重置，记得重新检查一遍。

## 预览 vs 播放

| | 👁 预览 | ▶ 播放 |
|---|---|---|
| 是否进 Play 模式 | 否（编辑器里直接渲染） | 是 |
| 从哪开始 | 选中的行 | 选中的行 |
| 章节卡片 | 不播 | 播 |
| 用途 | 快速看立绘位置、镜头、字号 | 完整测试流程、分支、存档 |
| 会不会改场景 | **不会**（临时借用路径后还原） | 不会（测试行用 SessionState 传参） |

**重要**：编辑器里的「▶ 播放」不会污染场景文件——退出 Play 后，直接点 Unity 的 Play 按钮仍然会从主菜单正常开始。

## 常用工作流

### 新增一个角色

```
1. VN → 角色卡 → ＋ 新建角色
2. 填 id（英文）和显示名（剧本里的名字）
3. 选立绘、选语音、选位置
4. 保存
5. 剧本里写说话人 → 自动出图
```

### 让角色某一刻退场

```
1. 在那一行点「＋ 添加退场」→ 选角色
2. 之后这个角色即使再说话也不会被自动加回来
```

### 加一个分支

```
1. 在想分叉的行点「＋ 添加选项」
2. 每个选项填文字 + 目标节点
3. 在目标行设置「节点 ID」
4. 需要条件时填 condition（如 affection >= 2）
5. 左侧列表会显示 ◇ 和橙色底
```

### 加一个结局

```
1. 复制最后那条结局行
2. 改 endingCg / endingVideo / 背景
3. 改台词
4. endGame 保持勾选
```

### 换角色的立绘

```
1. VN → 角色卡 → 选角色 → 换图
2. 保存（自动同步到所有剧本）
```

### 调某一行的演出时序

```
1. 打开「演出顺序表」
2. ＋ 添加步骤，填时间
3. 勾选要同时发生的动作
```

## 素材规范

所有资源都在 `<项目>/` 下（下面用 `Recall` 举例）。

| 类型 | 位置 | 规范 |
|---|---|---|
| 背景 | `Resources/Recall/Arts/BG/` | PNG/JPG，任意比例（运行时等比裁切，不变形） |
| CG / 结局图 | `Resources/Recall/Arts/CG/` | 同上 |
| 立绘 | `Resources/Recall/Arts/Char/<角色id>/<表情>.png` | **透明 PNG**，画布高度一致，换表情时脚不会跳 |
| BGM | `Resources/Recall/Audio/BGM/` | OGG / WAV，自动循环 |
| 音效 | `Resources/Recall/Audio/SFX/` | 短音频 |
| 说话音 | `Resources/Recall/Audio/Voice/` | 建议 0.05~0.3 秒 |
| 字体 | `Assets/VN/Fonts/` | TTF，像素字体建议字号用 12 的倍数（**全项目共用**） |
| 剧本 | `Resources/Recall/Data/*.json` | 编辑器自动生成，不用手改 |
| 角色卡 | `Resources/Recall/Data/characters.json` | 用角色卡编辑器改 |
| Shader | `Resources/Shaders/` | 框架自带（**全项目共用**） |

**导入设置会自动处理**：`Assets/VN/` 下的图会被设成 Sprite + Point 过滤 + 无压缩（像素风不糊）。

## 故障排查

| 现象 | 原因 | 解决 |
|---|---|---|
| 立绘出现两个 | 剧本配的槽位和角色卡不一致 | 角色卡保存会自动对齐；或手动改成同一个槽位 |
| 旁白自动借用了别人的声音 | 名字匹配到了在场角色 | 检查说话人名字；或给该角色配 `voiceMode: none` |
| 打开就模糊 | 失明滤镜强度没归零 | 检查行里的 `useBlind` / `blind`；默认 0 应该是清晰的 |
| 新游戏跳到了后面的章节 | `startChapter` 被改 | 检查 `VNPlayer.startChapter` 是否指向 story01 |
| 编辑器播放后，直接 Play 从中间开始 | 旧版本的 bug | 已修复：现在用 SessionState 传参，不写场景 |
| 保存角色卡后剧本没变 | 没点「保存」 | 工具栏会显示 `● 未保存` |
| 改完代码后 VN 场景缺 UI | 新字段需要重建场景 | `VN → 构建场景（或重建）` |
| 打包报错找不到脚本 | 编译错误 | 先看 Console，清掉红色错误 |
